#Cryptanalysis-Game#
--------------------------------

#About#

This program is a cryptanalysis game in which the user guesses a 3 digit number within a limited amount of attempts. The program does the following:
- Shows how many correct digits and misplaced digits are in a user's guess.
- Prompts the user to enter a valid input if the user's input is invalid.
- Produces a visual window that displays the user's most recent input.
- Changes the status of certain areas of the visual window based on the amount of correct or misplaced digits in the user's input.

--------------------------------

#Local Setup and Installation#

This program uses pygame and assets within the original file to operate. In order for the program to operate locally, follow these steps:
1. Ensure all files within the game's folder are downloaded properly. They should all be within the same folder by default.
2. Use the program named "spacepod_escape.py" as this is the program that the game is in.
3. Ensure that when running the program that all local asset files remain in the exact same root folder directory as the execution script.
4. Ensure that pygame in installed.
5. Run the program.
